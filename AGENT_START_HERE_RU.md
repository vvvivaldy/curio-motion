# Начало работы агента

Curio Motion — локальный проект для 2D-анимации кодом. В поставке есть разные персонажи, предметные взаимодействия, стили, записанный звук и учебная инфографика. Это примеры и общие геометрические средства, а не автоматическое преобразование картинки в фильм.

## Прочитать и воспроизвести

1. [README_RU](README_RU.md): установка, Player и примеры.
2. [USAGE_RU](docs/USAGE_RU.md): задание, роли и порядок работы с человеком.
3. [Локальный навык](.agents/skills/curio-authoring/SKILL.md), [API](docs/API.md), [AUTHORING](docs/AUTHORING.md): фактические интерфейсы, scaffold и проверка.
4. [BETA](BETA.md): границы поставки и условия будущей 1.0. [Архитектура](docs/ARCHITECTURE.md) объясняет внутренние решения; старые QA-отчёты являются историей конкретных версий.

Нужны Node ≥22.12, npm, WebGL и установленный отдельно Chrome/Chromium. В корне проекта:

```sh
npm ci
npm run check
npm run dev
```

Открой напечатанный Vite адрес и `/player.html?example=raccoon-courier` или `/player.html?example=delivery-infographic`. `/viewer.html` показывает сохранённый фильм, `/player.html` рисует живые кадры из кода. Для быстрого открытия также есть `npm run demo:raccoon`, `npm run demo:infographic` и `npm run demo:cat`.

```sh
# macOS/Linux; CHROME_PATH нужен, если браузер не найден автоматически
export CHROME_PATH="/path/to/installed/chrome"
COMPOSITION_ID=RaccoonCourier RENDER_AUDIO_CODEC=aac npm run render
COMPOSITION_ID=DeliveryInfographic npm run render
```

PowerShell и остальные команды — в [DEVELOPMENT](docs/DEVELOPMENT.md). Приватные исходные референсы не нужны для Player и экспорта включённых сцен; повторение их старого reference-based review требует соответствующего оригинала.

## Создать свою сцену

Сохрани цельное задание пользователя в UTF-8 `inputs/ACTION.txt`, цельный референс — в выбранный файл. `inputs/` не является автоматически приватной папкой: не складывай туда секреты и не включай входы в общий архив. Затем:

```sh
npm run create:example -- --id new-owl --composition NewOwl \
  --reference inputs/whole.png --action-file inputs/ACTION.txt \
  --title 'New owl' --provenance 'User-supplied whole reference' \
  --width 1280 --height 720 --fps 24 --frames 288
```

Прочитай сгенерированные `authoring/new-owl.agent.md` и `.plan.md`. Команда создаёт новые файлы и отказывается от перезаписи: blank scene/settings, неизменённый ACTION, копию цельного входа, происхождение/хеши и v2-план. Регистрация сцены и метаданных остаётся явной ручной правкой. Команда не рисует персонажа и не интерпретирует задание. Для учебной пробы можно взять публичный `reference/amber-robot/design.svg` вместо личного входа.

## Короткий рабочий цикл

- Зафиксировать действие, стиль, длительность, опоры/хваты и конкретные критерии. Отдельно отметить факты референса и придуманные скрытые виды.
- Показать чистые контрольные рисунки и крайние позы до полного фильма. При поворотах — читаемые фронт/профиль/спину, постоянные стороны тела, независимую голову.
- Сделать постановку, переходы, шаги и удержания. Проверить непрерывность силуэта, анатомию, фактические контакты и соседние кадры смены контроллера/хвата.
- Выбрать эффекты по материалам, привязать к событиям, сохранить хвосты и паузы. Видимость и слышимость источника проверяются отдельно.
- Экспортировать полный официальный MP4 и проверить именно его. Критик возвращает конкретные кадры, человек принимает результат. Хеши, геометрия и успешные команды не принимают рисунок и звук за человека.

Проверяй только относящееся к изменению поведение, сохраняй исходный вариант и честно указывай пределы просмотра/прослушивания. Для небольшой сцены достаточно автора и человека. Независимый критик нужен при сложных взаимодействиях; математик подключается к конкретной геометрической проблеме.
