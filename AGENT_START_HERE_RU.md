# С чего начать новому агенту

Это самостоятельный Curio Motion, текущее развитие после релиза 0.1.0-beta.1. История другого проекта не нужна. Цель — мультфильмы и будущая маленькая библиотека программной 2D-анимации для нейросетевого автора. Вход: цельный референс и текст действия. Сейчас агент вручную написал два примера; автоматического генератора/очереди/API модели нет.

## Что уже работает

Оригинальная розовая лысая обезьяна с большими ушами, сонными глазами, светлой мордочкой/животом и мягким кульком на лямке. Все контуры построены TypeScript/Pixi Graphics; PNG только референс в viewer. Remotion Composition/useCurrentFrame/Player и официальный renderMedia дают 12 с, 1280×720, 24 fps, 288 кадров.

Постановка: 0–2.8 с подход лицом с переносом веса и встречными руками; 2.8–3.1 остановка; 3.1–5.1 front→3q→профиль с двумя небольшими поворотными шагами и неподвижной камерой; 5.1–6.35 две стопы поочерёдно встают на горизонтальную ступень; после 6.4 обезьяна почти неподвижна, фон/реклама идут вниз-влево. Неровные короткие моргания, взгляд на баннер, ленивое касание/почёсывание носа, возврат/пауза. Палец собирается у ладони и раскрывается ближе к контакту; не тянется иглой от живота.

Качество: цельный контур, читаемые колени/вес, стопы не дрейфуют на опоре, перекрытия без дыр, выразительные паузы, непрерывный поворот с исчезновением дальнего глаза/уха. После посадки ноги не шагают на месте. Не заменяйте живость постоянными синусоидами. Владелец сказал «уже неплохо» и разрешил standalone-передачу; это не одобрение универсального движка.

## Выполненный первый этап и дальнейшая работа

Baseline воспроизведён. Минимальный локальный TypeScript API выделен в `src/core/time.ts` и `src/core/stage.ts`: время/easing, проверка кадра, вычисление позы и типизированный контекст рисования. Пример подключён через `src/examples/pink-monkey/scene.ts`, прежний `createStage(host)` сохранён. Все 288 кадров нового фильма совпали с baseline; исходные визуальные материалы не изменены. Контракты — docs/API.md, результаты — docs/VERIFICATION.md. После извлечения выполнен первый пакет качества: общая апертура глаз/обрезка зрачка, шаги с удержанием позиции и направления, системы координат, геометрия ступеней и устойчивый IK. Следующий пакет добавил общие последовательности контактов, передачу нагрузки, перекат вокруг пятки/носка и ограничение высоты корпуса по досягаемости. Подход теперь состоит из четырёх продвигающихся шагов с посадкой веса; поворот и посадка используют те же механизмы. Третий пакет добавил согласованные контуры, локальные системы запястья, привязку точки контура к поверхности и два движения с паузами. Рисунок получает параметры кисти из позы; кривая носа и цель касания заданы одним источником. Пример использует эти библиотечные функции. Четвёртый пакет добавил общие цельные виды контуров и объёмную геометрию ступеней. Исправлены уши, ракурсы головы/мордочки/тела, сумка, стопы и непрозрачность эскалатора; все 575 полных поз движения совпадают с v4. Текущий фильм — docs/assets/demo-v5.mp4, GIF в README — docs/assets/demo.gif; исходные beta-материалы сохранены.

Перед дальнейшими изменениями прочитайте README/AGENTS/ARCHITECTURE/ROADMAP, выполните npm ci/check, откройте viewer/живой Player и проверьте check:port/render с существующим Chrome. Второй пример Эмбер выполнен по отдельному поручению владельца. Дополнительные примеры, инфографика, DSL, сервер и интеграция требуют отдельного поручения. Не расширяйте API без конкретного потребителя.

Файлы: src/examples/pink-monkey — постановка/рисунок; src/stage.ts — один draw(frame); src/remotion — thin bridge; scripts/render.mjs — официальный export. Референс+prompt в reference; готовые фильмы в docs/assets/demo.mp4 и docs/assets/baseline.mp4; outputs — только новые результаты команды render; происхождение/лицензии ASSETS и THIRD_PARTY_NOTICES. Node ≥22.12; Windows/Linux пока только инструкции, runtime проверен на Mac.

Владелец подтвердил destination `vvvivaldy/curio-motion`. Используйте только этот самостоятельный репозиторий. Фактический статус публикации и релиза — в docs/GITHUB_LAUNCH.md и repository-metadata.json; проверьте remote и штатную авторизацию перед GitHub-операциями. Поручение не включает платформенную интеграцию или деплой.

## Пятый пакет — второй персонаж

`src/examples/amber-robot` — компактный робот-садовник: берёт лейку, поливает дважды с паузой, возвращает её на стол, разжимает клешню и делает один кивок. Новый цельный референс — авторский SVG-эскиз `reference/amber-robot/design.svg`, созданный до кода анимации; это проверка переиспользования API, не автоматическое восстановление чужого рисунка. Сцена 960×640 / 30 fps / 300 кадров использует те же контуры, виды, глаза, IK, локальные системы и якоря. Из прежнего компонента выделен общий `createRemotionScene(scene)`, его используют обе Composition. Данные и анатомия обезьяны не импортируются вторым примером. Материалы первого фильма и GIF сохранены; все 288 кадров после замены моста совпали с v5. Новый фильм/GIF — `docs/assets/amber-robot.mp4` / `amber-robot.gif`; переключение в viewer/Player — `?example=amber-robot`, экспорт — `COMPOSITION_ID=AmberRobot npm run render`. Подробности — docs/REUSE.md и VERIFICATION.md. Ни автоматизация нейросетевого автора, ни третий пример этим поручением не разрешены.

## Шестой пакет — механика и процесс качества

Текущий робот — `docs/assets/amber-robot-v2.mp4`; прежний фильм и `amber-robot-v1.gif` сохранены. Общий `solvePlanarLimb` фиксирует сторону сгиба и отвергает недопустимые запястье/выпрямление. Лейка стоит в достижимой области и наклоняется вокруг захвата. Новый локальный процесс описан в `docs/AUTHORING.md`: планы `authoring/*.json`, промежуточные рендеры и финальные декодированные кадры, журнал ошибок, проверки хешей/актуальности и отдельные визуальные решения. Это выполненное поручение владельца; провайдер модели, автоматическое восстановление произвольного референса, третий пример и интеграция остаются вне задачи. Отчёт о реальных кадрах — `docs/reviews/process/README.md`.
