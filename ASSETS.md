# Artwork and media provenance

The whole pink-monkey reference is an original AI-generated design reference created for this experiment with the built-in image-generation tool. Its exact prompt is [IMAGEGEN_PROMPT](reference/IMAGEGEN_PROMPT.txt); its bytes and role are pinned in [authoring input](authoring-input.json). It was not imported from another studio or used as a runtime texture. No external character, advertisement brand, voice or music is included.

The authoring agent interpreted that reference and action as TypeScript geometry. The film, poster, controls and header are project-created outputs of this code/design process. The baseline film preserves the visually reviewed trial; the Remotion film is a separate official renderer output. They are labeled separately.

The root MIT license covers original source code. AI-reference provenance is disclosed rather than presented as human-drawn artwork or a guarantee of exclusive copyright. This handoff includes it as example input; the publishing agent should preserve this provenance and review distribution scope for the eventual repository. Dependency licenses do not confer rights to unrelated artwork. No proprietary fonts or third-party reference videos are bundled; sign lettering is constructed from code.

The quality-foundations development pass adds `docs/assets/demo-v2.mp4`, rendered from the updated TypeScript by official Remotion renderMedia, and `docs/assets/demo.gif`, a 720px/12 fps FFmpeg derivative for inline README playback. The original `demo.mp4` and `baseline.mp4` are preserved. Review contact sheets in `docs/reviews/` are labeled crops/frames of project-created films; they are evidence only, not scene textures.

The gait pass adds `docs/assets/demo-v3.mp4` from official Remotion renderMedia and updates the README GIF from that movie. Both earlier movie versions and the whole reference remain unchanged. Gait review sheets are project-created frame comparisons, never scene inputs.

The repository presentation pass adds `docs/assets/social-preview.png`: a project-created 1280×640 title card with a frame at 8.5 seconds from `demo-v3.mp4`, the existing project palette and system typography. It is documentation artwork only, not scene input.

Earlier films, reference and social card are unchanged. Hand review sheets are decoded project-created frames, not scene textures.
