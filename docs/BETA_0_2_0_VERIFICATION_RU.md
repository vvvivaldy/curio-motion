# Curio Motion 0.2.0-beta.1 — проверка локальной поставки

Дата: 1 ноября 2026. Отчёт фиксирует проверку подготовленного исходного ZIP до публикации. По поручению владельца он выпускается как [GitHub prerelease](https://github.com/vvvivaldy/curio-motion/releases/tag/v0.2.0-beta.1); npm-публикация не выполняется. В Git добавлены документы публикации и соответствующий manifest. Все исходники рендера, зависимости, звук и фильмы совпадают с проверенным ZIP.

- [ZIP, 76 999 940 байт](https://github.com/vvvivaldy/curio-motion/releases/download/v0.2.0-beta.1/curio-motion-0.2.0-beta.1.zip) — один корень `curio-motion-0.2.0-beta.1/`, 623 файла.

- MANIFEST.sha256 внутри покрывает остальные 622 файла. CRC и каждый файловый хеш проверены. `npm run verify:package` проверяет перечисленный исходный payload; добавленные после распаковки лишние файлы эта команда не ищет.
- Зависимости и кэши, `.git`, `qa`, `dist`, `outputs`, `.env` и восемь явно локальных цельных пользовательских референсов исключены. Их provenance/ACTION сохранены. Для воспроизведения сцен приватные исходные картинки не требуются; для повторения старого сравнения с ними нужен соответствующий вход.

## Что вошло

Собраны текущие общие механизмы движения, контактов и геометрии, принятые персонажные сцены, енот-курьер и самостоятельная инфографика. В инфографике один редактируемый `data.ts`: итог, доли и настоящий уникальный максимум вычисляются. Учебный контракт — три категории, целые значения 0…30, положительная сумма; другой диапазон требует пересмотра макета.

Сохранены фильмы и расширенный банк записанных эффектов с происхождением и лицензиями: 16 новых courier WAV-вариантов из 13 записей, всего 102 runtime audio-файла. Варианты нарезки не считаются самостоятельными исходными записями. Код MIT; Remotion, изображения и звук имеют отдельные условия в ASSETS и THIRD_PARTY_NOTICES.

Внутри есть README_RU, `docs/USAGE_RU.md`, установка/экспорт в DEVELOPMENT, инструкции AGENTS и локальный навык, готовые задания автору и критику. Scaffold создаёт заготовку файлов; рисунок и движение автор строит сам. Обычно достаточно автора и владельца; независимый критик полезен для сложных действий, математик — под конкретный дефект.

Поэтому полные экспорты B применимы к тем же входам рендера C; третьего повторного экспорта C не приписываем.

## Ограничения

Фактическая среда: macOS26.6.2 arm64, Node26.4.0, npm11.17.0, Chrome for Testing156.0.8078.4; дополнительное декодирование — FFmpeg9.0.2. Требование проекта Node≥22.12; отдельный прогон именно на минимальной версии не выполнялся. Windows/Linux browser/export не проверены. Для запуска нужен установленный Chrome/Chromium и WebGL, при необходимости CHROME_PATH; npm ci требует сеть, runtime аккаунтов и AI API-ключей не требует.

Контрольные кадры из закодированных MP4 осмотрены, файлы технически декодированы и воспроизведены до ended. Эти измерения не заменяют непрерывный художественный просмотр и прослушивание всей беты. Нового полного слухового принятия не заявляем. Мелкие известные предупреждения React/Vite и отдельный favicon404 при обычном live просмотре не означают отсутствующие источники сцены. Исторические скрытые CatStoryV1/V2 не входят в текущий default port-набор; текущая видимая версия — V3.

Геометрические проверки не гарантируют автоматически хорошую анатомию или постановку. Замечание о затухающих шагах после ухода енота из кадра сохранено в руководстве как дальнейшее улучшение; принятый фильм ради упаковки не менялся.

## Как начать и что дальше

Распаковать ZIP в отдельную папку → открыть корень в кодинг-агенте → прочесть README_RU и `docs/USAGE_RU.md` → `npm ci` → `npm run check` → live Player → официальный экспорт по DEVELOPMENT. Версия private:true: это исходный проект, не npm-пакет.

Следующий полезный шаг — реальное применение беты с фиксацией конкретных препятствий. Переход к1.0 обсуждаем отдельно: повторяемая установка/правка/экспорт новым пользователем, объявленная проверенная среда и ясные гарантии совместимости публичного API. Квоты новых функций, стилей или количества агентов нет. План и границы находятся в BETA и ROADMAP внутри архива.
