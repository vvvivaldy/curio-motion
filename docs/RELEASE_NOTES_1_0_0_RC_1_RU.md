# Curio Motion 1.0.0-rc.1

Локальный кандидат первого стабильного выпуска. Это редактируемая 2D-анимация на TypeScript: Pixi рисует, Remotion задаёт кадры, Player и официальный MP4. Публикация RC/1.0 этим текстом не выполнена.

В кандидате закреплены 20 stable API имён и правила совместимости, включены принятые персонажные примеры, 36-секундный «Утренний маршрут», записанный звук и редактируемая учебная инфографика. Есть blank scaffold, инструкции пользователю/агентам и повторяемая сборка с checksum/provenance и проверкой известных credential-паттернов.

Официальный объём — macOS arm64 с указанным Chrome/WebGL; контрольные Node 22.12.0 и 26.13.0 LTS. Windows/Linux не проверены. Установка: `npm ci`, `npm run check`, `npm run dev`. Проект остаётся source-project (`private: true`), не npm-пакетом или автоматической генерацией анатомии.

От stage 4 baseline меняются version metadata и документы; код сцен, зависимости, аудио и принятые фильмы сохраняются. Точный SHA, commit, повторные проверки и перенос прежних гейтов находятся во внешнем RC-отчёте рядом с ZIP. Старые SHA/receipts не переписаны как результаты новой версии.

Оригинальный код MIT; Remotion и recorded media имеют отдельные notices/условия. При переходе с 0.2 сохраните свой проект/фильм, распакуйте RC отдельно, перенесите исходники и установите зависимости из нового lockfile. Пути stable импортов сохранены; остальные helpers сохраняют experimental/internal статус.

Владельческая приёмка кандидата и решение о стабильной публикации ожидаются отдельно. Это подготовленный текст для рассмотрения, не опубликованная страница release.
