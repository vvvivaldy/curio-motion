# Как устроен первый звуковой черновик

Он добавляет звук к принятому HumanChair V3: все 348 кадров декодированного изображения совпали с немым фильмом. Шаги берутся из реальных `tracks[].end`, мягкая посадка — из `phases.sitContact`. Одна временная шкала Remotion управляет изображением и `Sequence`/`Html5Audio`; Pixi и функция позы звуки не запускают. Никакого дополнительного ускорения:14,5 секунды, 24 кадра/с.

Три варианта шага и мягкая посадка — оригинальные процедурные WAV. Короткий кандидат нагрузки стула сохранён, но в текущем миксе отключён до личного прослушивания. Слуховое качество и одобрение звука пока не подтверждены: модель не получает аудиовход. Численные проверки подтверждают синхронизацию/уровни/целостность, а не естественность.

## Получить WAV из кода

Генератор: `scripts/audio/generate_foley.py`, Python3 standard library, без пакетов, сети и записанных сэмплов. Точные seed, длительности, gain и параметры находятся в `SPECS` и функциях `step`/`seat`/`chair`. SHA исходника: `3e30413f6681aef4f61af53790c3a123080d759b9c6efddcf118cc571b672a77`.

Для новой копии используйте отдельную папку; команда поддерживает именно `--out`:

```sh
python3 scripts/audio/generate_foley.py --out qa/audio-regenerated
```

Проверить побайтное воспроизведение существующих 5 WAV без их изменения:

```sh
python3 scripts/audio/generate_foley.py --verify --out public/audio/human-chair
```

На исходном Mac с Python 3.12.8 повтор совпал побайтно. На другой платформе сначала сравните SHA: функции libm могут различаться. Без `--verify` генератор перезаписывает файлы указанной папки, поэтому не направляйте экспериментальные варианты сразу в `public`. После уже выполненного экспорта WAV не перегенерировались. Происхождение, SHA и положение атаки каждого файла — в `public/audio/human-chair/provenance.json`.

## Монтаж и проверка

`src/examples/human-chair-sound/cues.ts` содержит фиксированные события, вариации и громкости. Известная начальная тишина WAV учтена при привязке атаки; случайного выбора во время проигрывания нет. Шаги, приземляющиеся за кадром, в этом небольшом trial пропущены.

```sh
CHROME_PATH='/path/to/existing/chrome' npm run render:sound
```

Официальный `renderMedia` пишет отдельный `docs/assets/human-chair-sound-v1.mp4` с AAC. `qa/human-chair-sound-v1/full-sound-binding.json` связывает исходники, WAV, cues, provenance, параметры экспорта и настоящий MP4; до/после рендера проверяется неизменность входов. Немой V3 и 17 предыдущих фильмов сохранены.

Live Player: `/player.html?example=human-chair-sound`; готовый фильм: `/viewer.html?example=human-chair-sound`. Автовоспроизведения со звуком нет; используйте штатные Play/Pause, mute, volume и перемотку. Direct Pixi остаётся немым.

История содержит9-секундный первоначальный draft с необязательным звуком стула и актуальный7-секундный draft без него. Полный файл использует только актуальный вариант. Все художественные решения по звуку требуют прослушивания владельцем; публикация не выполнялась.
