# Енот-почтальон

16-секундный пример персонажа и взаимодействия с предметом: енот подбегает к стойке, берёт конверт, переворачивает его, перекладывает хват и опускает письмо в сумку. Рисунок плоский, векторный; готовое видео служит образцом, а Player исполняет код сцены.

- Ключ примера: `raccoon-courier`.
- Композиция экспорта: `RaccoonCourier`.
- Размер: 1280 × 720, 24 кадра/с, 384 кадра.
- [Сохранённый принятый фильм](assets/raccoon-courier-anatomy-sound-v3.mp4).
- Код: `src/examples/raccoon-courier/`.
- Исходное задание: `authoring/raccoon-courier.action.txt`.
- План контрольных кадров: `authoring/raccoon-courier.json`.

Запустите проект по [руководству установки](../README.md), затем выберите енота в галерее. Прямые страницы на локальном сервере: `/player.html?example=raccoon-courier` и `/viewer.html?example=raccoon-courier`. Player показывает живой код, Viewer — сохранённый фильм.

Для нового экспорта из корня проекта в командной оболочке macOS/Linux:

```sh
COMPOSITION_ID=RaccoonCourier RENDER_AUDIO_CODEC=aac npm run render
```

Новый файл появится в `outputs/raccoon-courier-remotion.mp4`; сохранённый образец не перезаписывается. Браузер Chrome/Chromium устанавливается отдельно; при необходимости задайте `CHROME_PATH` по общей инструкции.

## Что изучать в примере

`motion.ts` содержит чистую функцию позы, обычный бег, торможение и явные состояния хвата. Конверт поворачивается при одном основном хвате. При переносе лапы к новой точке другая лапа продолжает держать лист. После совмещения с горловиной письмо опускается внутрь; последний хват освобождается уже ниже края сумки.

Длина костей и достижимость цели не доказывают правильность позы. Здесь существующий `solvePlanarLimb` дополнен авторским плечевым сектором и направлением сгиба. Эти значения рассчитаны для конкретного тела и низкой работы с конвертом: не копируйте их как универсальную анатомию всех персонажей. Если нужная поза не проходит ограничения, сначала пересмотрите стойку, высоту предмета и порядок перехватов.

`illustration.ts` рисует цельные контуры, ботинки и стороны конверта. `sound.tsx` привязывает отдельные записи обуви, бумаги, дерева и кожи к действиям. В текущем фильме 30 звуковых событий, восемь WAV из семи исходных записей. [Каталог и условия использования звуков](SFX_CATALOG_RU.md) перечисляют происхождение и обработку. Уходящий за край персонаж в будущей сцене может оставаться слышимым с постепенным удалением; сохранённый образец не является универсальной моделью акустики.

## Проверка и границы примера

`npm run check` включает `scripts/check-stage6.ts`: длины конечностей, плечевой сектор, опоры, непрерывность, хват и отпускание. Четыре неправильные позы прежнего фильма сохранены как геометрическая регрессия в `scripts/fixtures/raccoon-revised-bad-arms.json`. Адресная проверка живого рисунка и Remotion Player:

```sh
EXAMPLE=raccoon-courier npm run check:port
```

Она выполняет 205 сравнений кадров, включая соседние кадры переворота и перенос к сумке. Это проверка совпадения рендеров и повторного перехода по времени. Правдоподобие анатомии, видимость обеих цепей рук, движение в обычном темпе и звучание проверяются отдельно по фактическому результату.

В бету включён ровно принятый ранее фильм с SHA-256 `00b762a4de7b6024258f9032faebd95a6059bcfb0d4e0f8668f3d8a822241092`. Интеграция исходников в новую поставку меняет их общую идентичность; принятие этого старого фильма не заменяет проверку нового экспорта.

Цельный референс владельца приватный и не включён. В `reference/stage6-private/raccoon-courier-input.json` остались его хеш, происхождение и явный режим `local-only`. Для запуска и экспорта рисунка PNG не нужен. Повторный исходный процесс сравнения с референсом возможен только с отдельно предоставленным владельцем оригиналом; не заменяйте его готовым кадром фильма и не записывайте фиктивную приёмку.
