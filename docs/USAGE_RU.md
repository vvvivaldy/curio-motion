# Как пользоваться Curio Motion с агентом

[Установка и команды](DEVELOPMENT.md) · [Инструкции агента](../AGENT_START_HERE_RU.md) · [Поддержка 1.0](SUPPORT_RU.md)

## Настроить папку один раз

1. Распакуй поставку в отдельную рабочую папку. Поставь Node ≥22.12, npm и Chrome/Chromium. Установка зависимостей требует доступа к npm; для Player и экспорта не нужны аккаунты, API-ключи или облачный генератор.
2. Открой **корень проекта** в своём редакторе/кодинг-агенте, дай доступ к этой папке. Выполни `npm ci`, затем `npm run check` и `npm run dev`.
3. Открой `/player.html?example=raccoon-courier` по адресу Vite. Это живая сцена из исходников; `/viewer.html?example=raccoon-courier` показывает сохранённый фильм. Нажми play для звука: браузер может блокировать автоматическое воспроизведение.
4. Для MP4 укажи `CHROME_PATH`, если браузер не найден. Первый экспорт и команды PowerShell описаны в [DEVELOPMENT](DEVELOPMENT.md). Браузерный путь проверен на macOS; Windows/Linux пока требуют собственной проверки.
5. Скажи агенту прочитать `AGENTS.md` и `.agents/skills/curio-authoring/SKILL.md`. Если его клиент сам находит проектные инструкции — они уже лежат в нужной папке. Если не находит, передай эти пути явно. Переносить инструкции в глобальные настройки и пересылать весь наш чат не нужно.

Сохрани референс целым файлом и отдельный `ACTION.txt`. Копируемый начальный текст для агента — [PROMPT_FOR_NEW_AGENT_RU.txt](../PROMPT_FOR_NEW_AGENT_RU.txt). Новому участнику достаточно задания, локальных инструкций, текущих исходников, выбранного MP4 и открытых замечаний с кадрами.

## Выбрать исходную сцену

| Задача | Где смотреть |
| --- | --- |
| Простая предметная анимация | `src/examples/amber-robot/` |
| Персонаж, хват и перенос предмета, записанный звук | `src/examples/raccoon-courier/` |
| Короткий сюжет, повороты, бег, несколько событий | `src/examples/cat-picture-story/` — текущий вход `scene-v3.ts` |
| Инфографика | `src/examples/delivery-infographic/`; учебные числа в `data.ts` |

Для нового примера используй `npm run create:example`, а не переименовывай чужую анатомию. Scaffold создаёт пустую сцену; агент авторски строит нужные формы и движение. В инфографике проверяй значения, суммы, доли, общую шкалу, читаемость и подпись учебных/реальных данных. Для учебной правки меняй только три значения в `data.ts`, например 9/21/30: итог и доли вычисляются. Контракт примера — ровно три категории, целые значения 0…30, положительный итог. Другой диапазон или число категорий требует пересмотра макета.

## Что дать автору

Полезное задание содержит цельный референс, последовательность действий, стиль, длительность и критерии приёмки. Например:

> Сделай 12-секундную сцену 1280×720 / 24 fps по приложенному цельному референсу. Робот подходит к тумбе, берёт коробку, прижимает ближе к корпусу и уходит. Стиль — плоская бумажная аппликация. Коробка не проходит сквозь тело, опорные ноги не скользят, локти сохраняют естественный сгиб. Шаги — по дереву; короткий звук при касании коробки. Сначала покажи контрольные позы подхода, хвата и переноса. Используй общие механизмы Curio Motion. Сдай MP4, исходники, выполненные проверки и оставшиеся ограничения; ничего не публикуй.

Сначала принимаем рисунок и контрольные позы; затем постановку и переходы. Для сложного захвата или поворота проверяем короткий фрагмент с соседними кадрами до полного рендера. После изменений в темпе заново сверяем звуковые атаки с контактами. Удаляющиеся шаги могут звучать после ухода персонажа из кадра: слышимость заканчивается по смыслу сцены, не по границе картинки.

## Сколько агентов нужно

**Обычно достаточно одного автора и человека, который принимает результат.** Автор может совместить короткий сценарий, рисунок, движение и подбор звуков. Человеку не нужно заранее собирать режиссёра, аниматора, математика и звукорежиссёра по отдельности.

Второй независимый агент полезен как критик при хватах, поворотах, смене ракурса и сложной анатомии. Он получает результат и критерии, а не обязан защищать решения автора. Математика подключаем под конкретную проблему: направление сустава, пересечение поверхностей, проекцию или ошибку общей геометрии. Исправления общего кода лучше назначать одному ответственному, чтобы два автора не меняли его одновременно.

Задание критику:

> Прочитай AGENTS.md и критерии сцены. Проверь этот точный MP4 и соответствующие исходники. Сначала чистые кадры и движение, затем геометрические отчёты. Сравни до/после: силуэт, обе полные цепи конечностей, ближние/дальние части, опоры, хват/передачу предмета, переходы и звук. Для каждого обязательного дефекта дай время/кадр, симптом и минимальную предлагаемую правку. Отдельно укажи кадры, непрерывный просмотр и звук, которые реально проверил. Не объявляй непросмотренное принятым. Верни замечания координатору/автору; человек принимает финал.

Для передачи задачи достаточно короткой записи: **что должно произойти → версия/кадр → что сейчас неверно → критерий исправления → путь к результату**. Большие общие пожелания вроде «улучши физику» уточняем на конкретном видимом действии.

## Готовый результат

Официальный MP4, редактируемая сцена, актуальные материалы/лицензии, выполненные технические проверки и честные ограничения. Проверяем именно закодированный фильм; успешный экспорт не доказывает хорошую анатомию, темп или звук. Если агент не может слушать звук или наблюдать целый ролик, эту часть принимает человек. [Полный процесс автора](AUTHORING.md) хранит более подробные контрольные материалы, когда задача этого требует.
