# Поддержка 1.0

Официально проверен полный путь установки, просмотра и экспорта на **macOS arm64**. Windows/Linux могут работать, но их Player и MP4 пока не проверены. [Релиз и результаты проверок](RELEASE_1_0_0_RU.md).

| Область | Поддерживаемый объём |
| --- | --- |
| Поставка | Редактируемые TypeScript-исходники, локальные команды; не npm-пакет и не глобальный CLI |
| Node / npm | Минимум Node 22.12.0 / npm 10.9.0; контрольная версия выпуска Node 26.13.0 / npm 11.20.0. Это проверка двух версий, не всех версий выше минимума |
| Просмотр и MP4 | Baseline выпуска: macOS 26.6.2 arm64, Chrome for Testing 156.0.8078.4 с WebGL |
| Linux CI | Установка зависимостей, типы, тесты и сборка. Это не проверка браузерного Player или MP4 |
| Зависимости | Зафиксированы в package-lock; использовать `npm ci`. Pixi рисует, Remotion задаёт кадры и экспорт |
| Браузер | Chrome/Chromium устанавливается отдельно; при необходимости указать исполняемый файл в `CHROME_PATH`. Автоматической загрузки нет |
| FFmpeg | Дополнительные GIF/baseline/review утилиты могут требовать системный FFmpeg; основной MP4 использует установленный Remotion encoder |
| Входы | Типизированная сцена; цельный референс и ACTION нужны автору. Для запуска включённых сцен приватные референсы не требуются |
| Качество | Численные проверки не гарантируют анатомию, постановку или подходящий звук. Нужен просмотр результата |

Размеры и длительность сцены ограничены возможностями машины и браузера. Нет универсальной гарантии скорости, памяти или одинаковых пикселей между разными GPU.

`npm ci` требует доступа к npm. Для работы библиотеки не нужны AI API, аккаунт нейросети, Docker или облачный сервис.

Начало работы — [README](../README_RU.md); команды и диагностика — [DEVELOPMENT](DEVELOPMENT.md). В отчёте об ошибке укажи сцену, кадр, вход и версии среды. Не включай приватные референсы и секреты в публичный отчёт.
