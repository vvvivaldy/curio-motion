# Выпуск 1.0

Пять пакетов подготовки завершены; 1.0.0-rc.1 принят владельцем. Отдельно разрешена стабильная публикация. Текущий операционный шаг — [этап 6](STAGE_6_RU.md): подготовить версию 1.0.0, проверить точный ZIP, опубликовать и проверить скачанный публичный asset.

[Руководство 1.0](RELEASE_1_0_0_RU.md) · [Принятый RC baseline](RELEASE_1_0_0_BASELINE.json) · [План](PLAN_1_0_RU.md).

Завершение выпуска подтверждают внешние RELEASE_VERIFICATION_RU.md и RELEASE_PUBLIC_VERIFICATION.json, не текст этого замороженного снимка. После публикации развиваем библиотеку по реальным затруднениям пользователей: конкретные ошибки установки/движения/инфографики/звука и улучшение инструкции. Новые стили, sound packs, универсальный риг, cloud rendering и дополнительные ОС не являются квотой ради номера версии.
