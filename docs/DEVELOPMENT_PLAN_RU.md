# План развития Curio Motion

Опубликована бета [0.2.0-beta.1](https://github.com/vvvivaldy/curio-motion/releases/tag/v0.2.0-beta.1). Пакеты 1–4 [плана до 1.0](PLAN_1_0_RU.md) завершены. Сейчас готовится [локальный 1.0.0-rc.1](RC_1_0_0_RU.md); приёмка RC и разрешение публикации остаются за владельцем. Этот краткий документ сохраняет контекст развития; подробный новый план — основной.

## Что уже проверяли на законченных задачах

Общие механизмы использованы в разных персонажах, переносе коробки, посадке/подъёме, беге, захватах, поворотах и коротком сюжете. Пробы рисунка включают линию, бумажную аппликацию и неоновый вариант. Есть записанные звуки, а также самостоятельная учебная инфографика.

Независимый автор получил публичную копию без истории прежнего чата и сделал енота-курьера и инфографику. Первый фильм енота выявил ошибки передачи письма и анатомии; исправленный фильм принят владельцем. Перенос к сумке выполнен без выворачивания плеча, библиотека звуков расширена. Замечание про слышимые удаляющиеся шаги после ухода за кадр сохранено как полезный принцип для следующих сцен, а не обязательная переделка принятого фильма.

Это опыт конкретных задач с исправлениями, не доказательство автоматической генерации любого сюжета. История и исходные фильмы сохраняются; старые отчёты относятся к своим версиям.

## Выполненная подготовка и следующий шаг

| Шаг | Полезный результат |
| --- | --- |
| Собрать поставку | Один набор исходников, примеров, звуков/прав и действующих команд; без приватных входов и скрытых локальных зависимостей |
| Подготовить вход | Короткая установка, живой пример и MP4; инструкции автору/критику и готовые задания |
| Чистое испытание | Новый агент по архиву меняет сцену и данные инфографики, экспортирует оба результата; фиксируем реальные затруднения |
| Подготовить и опубликовать бету | Проверенный архив, контрольные суммы, результаты и ограничения; владелец разрешил GitHub prerelease |
| Использовать бету | Исправлять повторяющиеся проблемы новых пользователей и только затем решать о 1.0 |

## Чем 1.0 будет отличаться

Бета допускает изменения интерфейсов с объяснением. 1.0 требует определённого поддерживаемого API, ясной совместимости/миграций и воспроизводимого пользовательского пути на явно заявленных системах. Стабильность не означает идеальную анатомию по любому референсу: финальный фильм по-прежнему смотрит и принимает человек.

Новые платформы, стили и большие системы не являются условием ради круглого номера. Если честно заявляем macOS как проверенный браузерный путь, сначала закрепляем его; Windows/Linux не объявляем проверенными по одной успешной сборке CI.

## Как выбирать следующее улучшение

Берём конкретное затруднение: что пользователь не смог запустить, какой сустав вывернулся, где потерялся хват, почему неверны числа или не подходит звук. Исправляем минимальную причину, сравниваем до/после и проверяем затронутое поведение. Общий механизм добавляем при реальной повторной потребности. Для обычного ролика достаточно автора и человека; сложные взаимодействия отдаём независимому критику, математика зовём для конкретной геометрии.
