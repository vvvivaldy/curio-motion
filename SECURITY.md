# Security reporting

This is a local prototype, not a hosted service. Do not open public issues containing secrets or exploit details involving a third party. After publication, use GitHub private vulnerability reporting if the repository enables it; otherwise ask the maintainer for a private channel without disclosing sensitive information publicly. No reporting mailbox, bounty or response SLA is configured.

Only the current beta is maintained here. Do not load untrusted scene code: it executes JavaScript in a local browser. The local render uses a browser with `--no-sandbox` for the controlled example; isolate untrusted content rather than treating this as a security boundary. Dependencies, Chrome and system tools have their own update policies; this package does not claim a completed security audit.
