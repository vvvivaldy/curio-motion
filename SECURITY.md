# Security reporting

This is the locally prepared 1.0.0-rc.1 source project, not a hosted service. Do not open public issues containing secrets or exploit details involving a third party. After publication, use GitHub private vulnerability reporting if the repository enables it; otherwise ask the maintainer for a private channel without disclosing sensitive information publicly. No reporting mailbox, bounty or response SLA is configured.

The current development candidate is 1.0.0-rc.1; the latest published prerelease remains 0.2.0-beta.1. Preparing the RC does not claim a stable 1.0 publication or a security-support SLA for older versions. Do not load untrusted scene code: it executes JavaScript in a local browser. The local render uses a browser with `--no-sandbox` for the controlled example; isolate untrusted content rather than treating this as a security boundary. Dependencies, Chrome and system tools have their own update policies; this package does not claim a completed security audit.
