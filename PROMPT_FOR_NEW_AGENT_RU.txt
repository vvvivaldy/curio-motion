Ты работаешь с самостоятельным проектом Curio Motion из этой папки. Прочитай AGENTS.md, AGENT_START_HERE_RU.md, README.md, docs/ARCHITECTURE.md и docs/ROADMAP.md. Не требуется история другого чата.

Проект исследует подход «нейросеть прочитала цельный референс + действие и написала рисунок/движение кодом». Сейчас реализован только один авторский пример, не автоматический сервис. PixiJS строит новые векторные контуры по pose(t); Remotion управляет Composition/useCurrentFrame/Player и официальным renderMedia. Не подменять сцену MP4/PNG-кадрами, не нарезать референс на куклу.

Сначала воспроизведи baseline: npm ci, npm run check, live Player/viewer, npm run check:port и npm run render с существующим Chrome. Проверь реальный фильм: подход/перенос веса, плавный поворот, горизонтальные ступени/неподвижные опоры, рука/палец у носа, непрерывность силуэта и осмысленные паузы. Исходные одобренные визуальные материалы сохраняй как baseline.

Первый этап выполнен: минимальный TypeScript API выделен в src/core/time.ts и src/core/stage.ts; подключение примера — src/examples/pink-monkey/scene.ts. Контракты — docs/API.md, историческая проверка сохранения всех 288 кадров при извлечении — docs/VERIFICATION.md. Последующий первый пакет качества добавил общие апертуры глаз, шаги с удержанием позиции/направления, координатные преобразования, геометрию ступеней и устойчивый IK. Следующий пакет добавил последовательности шагов, передачу нагрузки, пятку/носок и общие ограничения высоты корпуса. Третий пакет добавил согласованные контуры, локальные системы кисти, контактные якоря и отдельные движения с паузами. Четвёртый пакет добавил общую интерполяцию цельных видов и объёмную геометрию ступеней: исправлены уши, ракурсы головы/мордочки/тела, сумка, стопы и непрозрачность эскалатора; движение сохранено. Текущий пример использует эти функции; новый фильм — docs/assets/demo-v5.mp4, GIF в README — docs/assets/demo.gif. Исходные beta-фильмы сохранены. Не строй большой DSL/универсальный движок/платформу. Второй пример и интеграция — отдельные будущие поручения. При проблеме сравни реальные кадры, не оправдывай плохой рисунок одними метриками.
